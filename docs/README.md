# README media

[Back to the project README](../README.md#screenshots--demos) · [GitHub repository](https://github.com/vijayanand1505/Entertainment-Hub)

These assets document the implemented Entertainment Hub interface. They were captured from the local app in Google Chrome using isolated demonstration browser sessions, rather than a user's existing browser profile.

- **19 JPEG screenshots:** desktop and mobile discovery, filters, search, title details, watching options, trailers, cast profiles, watchlist, recent history, collections, recommendations, appearance, and Movie Night Match.
- **`demos/feature-preview.gif`:** an eight-scene animated overview, 960 × 600, approximately 19 seconds, looping.
- **`demos/feature-tour.webm`:** a silent desktop feature walkthrough, approximately 58 seconds, 1280 × 800. The final scenes show the phone layout.
- **`demos/movie-night-match.webm`:** a silent room walkthrough, approximately 21 seconds, 1280 × 800, from lobby through private voting to the shared reveal. A second demo participant votes from another session.

## Capture notes

The sample watchlist, history, collections, and participant names were created for these captures. Movie metadata and artwork come from TMDB; trailer frames come from the embedded YouTube player. The placeholder invite origin `https://your-app.example` replaces the computer's local network address in the room screenshot and recording. It is not a live deployment.

When refreshing the media, use a clean browser profile, wait for visible artwork to load, and avoid recording API keys, participant access tokens, private network addresses, or real user data. Keep the filenames linked from the root README, or update those references together. Store screenshots in `images/` and recordings in `demos/`.
